JOM KIRA! ANDROID - PROJEK SUMBER VERSI 4

PENTING:
Fail ini ialah projek sumber Android Studio untuk membina APK. Ia BUKAN fail APK yang sudah dibina.

CARA MEMBINA APK:
1. Pasang Android Studio pada komputer.
2. Ekstrak ZIP ini.
3. Android Studio > Open > pilih folder Jom_Kira_Android_Project.
4. Tunggu Gradle Sync selesai. Sambungan internet mungkin diperlukan untuk memuat turun Android Gradle Plugin dan Android SDK.
5. Pilih Build > Build Bundle(s) / APK(s) > Build APK(s).
6. Apabila binaan berjaya, pilih Locate. APK biasanya berada di app/build/outputs/apk/debug/app-debug.apk.
7. Pindahkan APK ke telefon Android dan buka fail itu untuk memasang. Android mungkin meminta kebenaran memasang aplikasi daripada sumber tersebut.

APA YANG DISERTAKAN:
- Aplikasi HTML Jom Kira! dibungkus dalam Android WebView.
- JavaScript dan simpanan setempat pelayar diaktifkan.
- Aplikasi boleh dibuka tanpa hosting untuk fungsi yang berjalan secara setempat.
